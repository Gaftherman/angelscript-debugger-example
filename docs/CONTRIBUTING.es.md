# Contribuir a AngelScript Debugger Example

**[English](../CONTRIBUTING.md)** | **[Español](CONTRIBUTING.es.md)**

Gracias por ayudar. Se agradecen los informes de errores, las correcciones, la documentación y los ejemplos.

## Informar de un problema

Abre una [incidencia](https://github.com/angelscript-tools/angelscript-debugger-example/issues) con la versión que usas, tu sistema operativo, los pasos para reproducirlo y la salida que viste. Lo que más ayuda es un script de pocas líneas que reproduzca el problema.

## Proponer un cambio

1. Haz un fork del repositorio y crea una rama desde `main`.
2. Mantén cada cambio pequeño y enfocado, con pruebas cuando cambie el comportamiento.
3. Escribe los mensajes de commit como `tipo(ámbito): descripción breve en imperativo` sin punto final. Tipos: `feat`, `fix`, `test`, `perf`, `refactor`, `style`, `docs`, `chore`.
4. Abre una pull request que explique qué cambió y cómo lo comprobaste.

## Compilar y probar

~~~text
> .\run-demo.cmd --build-only
> .\run-demo.cmd
~~~

El núcleo del depurador viene del submódulo `external/angelscript-dap`. Las pruebas de la sesión DAP están en la rama `tests`.

## Estilo

Mantén el ejemplo pequeño y legible. Sigue `.editorconfig` (LF, UTF-8).
